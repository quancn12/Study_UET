# Thư mục chứa tài liệu gốc môn học (Raw Materials)

Hãy thả mọi file bài giảng của bạn vào đây:
- Slide bài giảng: `.pptx`, `.ppt`
- Giáo trình / Đề cương / Ebook: `.pdf`
- Đề cương / Bài tập / Note: `.docx`, `.doc`, `.txt`, `.md`
- Link bài giảng trên web: Bạn có thể lưu vào 1 file `links.txt` trong thư mục này.

Sau khi thả file, trợ lý AI sẽ tự động đọc, phân tích các chuyên đề và tổng hợp thành các bài học trực quan trên website!
