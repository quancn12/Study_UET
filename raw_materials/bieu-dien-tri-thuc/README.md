# Thư mục chứa tài liệu gốc môn: Biểu Diễn Tri Thức và Tìm Kiếm Nâng Cao

👉 **Thả toàn bộ file tài liệu của môn này vào đây:**
- Slide bài giảng: `.pptx`, `.ppt` (ví dụ: `Chuong1_TimKiemHeuristic.pptx`, `Chuong2_A_Star.pptx`...)
- Tài liệu PDF, sách giáo trình, đề thi các năm
- Ghi chú Word (`.docx`) hoặc link bài giảng (lưu vào `links.txt`)

Sau khi thả file vào thư mục này:
1. Bạn có thể gửi file trực tiếp cho Claude Sonnet kèm theo **Master Prompt dành cho môn Biểu diễn tri thức**.
2. Hoặc nhờ tôi chạy script trích xuất nội dung văn bản bằng lệnh:
   `python scripts/extract_text.py raw_materials/bieu-dien-tri-thuc`
